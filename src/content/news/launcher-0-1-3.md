The Linux AMD64 launcher now has its own update flow, separate from game client updates.

## Updating the launcher

- The launcher checks the trusted local release library at startup and when you choose **Check for Updates**.
- Select **Update Launcher** to open the desktop package installer and approve the upgrade. Once it completes, select **Restart Launcher**.
- The launcher keeps your installed game and settings across the upgrade. The Updates page shows the launcher and game client versions separately.

## Availability

Version **0.1.3** is a Linux development package for local testing. Public download availability will be announced on this site.
